## Features

<CardGrid>
  <Card title="Configurable systolic array" icon="setting">
    Parameterized grid dimensions, data types and dataflows, from 8x8 up to 64x64 PEs.
  </Card>
  <Card title="OS, WS and IS dataflows" icon="random">
    Output-stationary, weight-stationary and input-stationary schedules, through L1
    stream buffers with no bubbles between tiles.
  </Card>
  <Card title="A KPU compute tile" icon="puzzle">
    `SystolicTop` follows kpu-sim's CSP model: the BlockMover and the Streamer push
    whole tiles between L3, L2 and L1 on credits and tile-ready tokens.
  </Card>
  <Card title="Modern Python" icon="seti:python">
    A clean, type-hinted Python 3.10+ codebase on Amaranth HDL, verified with the
    Amaranth simulator and cocotb on Verilator.
  </Card>
</CardGrid>

## Quick start

```bash
# Install
git clone https://github.com/stillwater-sc/systars.git
cd systars
just setup
source .venv/bin/activate

# Run tests
just test
```
